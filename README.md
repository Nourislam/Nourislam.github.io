# Afus — برامج جزائرية للمحلات

موقع شركة Afus وتجربة برنامج **Afus Boutique** على الويب: https://nourislam.github.io

هذا المستودع يحتوي على ملفات الموقع المبنية فقط (HTML وCSS والصور والتجربة). يُبنى من مستودع البرنامج بالأمر `npm run build:site`.
